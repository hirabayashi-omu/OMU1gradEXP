📖 排ガス浄化・三元触媒 ＆ 空燃比フィードバック制御 基礎理論

1. 三元触媒（Three-Way Catalyst: TWC）の化学反応機構

ガソリンエンジンの排気ガスに含まれる3大有害物質（**CO: 一酸化炭素**、**HC: 未燃炭化水素**、**NOx: 窒素酸化物**）を、貴金属（白金 Pt、パラジウム Pd、ロジウム Rh）の触媒作用により同時に酸化・還元して無害な $\text{CO}_2, \text{H}_2\text{O}, \text{N}_2$ に変換します。

【酸化反応 (Pt, Pd)】: 2CO + O₂ ➔ 2CO₂
【酸化反応 (Pt, Pd)】: CₙHₘ + (n + m/4)O₂ ➔ nCO₂ + (m/2)H₂O
【還元反応 (Rh)】: 2NOₓ ➔ N₂ + xO₂ (または 2NO + 2CO ➔ N₂ + 2CO₂)

2. 触媒浄化ウインドウ（A/F ≈ 14.7）とO2センサ特性

3成分を同時に高効率（90%以上）で浄化できるのは、**理論空燃比（$\text{A/F} = 14.7, \lambda = 1.0$）のごく狭い領域（ウインドウ）** に限られます：

  • リッチ側（A/F < 14.7, 空気不足）: 残留酸素が不足するため、CO・HCの酸化浄化率が急激に低下します。O2センサは起電力 $\approx 0.9\text{ V}$（高）を出力します。
  • リーン側（A/F > 14.7, 空気過剰）: 酸素が余る酸化雰囲気となるため、NOxの還元浄化率が激減（ほぼ0%）します。O2センサは起電力 $\approx 0.1\text{ V}$（低）を出力します。

3. ジルコニアO2センサとネルンストの式

高温（300℃以上）の安定化ジルコニア（$\text{ZrO}_2$）は酸素イオン導電体となり、大気側（基準酸素分圧 $P_{\text{O2, ref}}$）と排気側（排気酸素分圧 $P_{\text{O2, exh}}$）の濃度差に応じて起電力 $E$ が発生します：

E = \frac{R \cdot T}{4F} \ln\left( \frac{P_{\text{O2, ref}}}{P_{\text{O2, exh}}} \right)

ストイキ（$\lambda = 1.0$）を境に排気中酸素濃度が数桁オーダーで激変するため、起電力はステップ状にスイッチングします。

4. ECUクローズドループ制御とセリア（OSC: 酸素ストレージ）

ECUはO2センサ信号（リッチ/リーン）を監視し、燃料噴射量を微小補正（ディザリング）してA/Fをウインドウ内に維持します。触媒内に担持されたセリア（$\text{CeO}_2$）は、リーン時に酸素を吸蔵し、リッチ時に放出して酸化を助ける「酸素ストレージバッファ（OSC）」として機能します。

5. EGR（排気再循環）システムによるNOx低減

不活性な排気ガスの一部を吸気管に再循環させることで、燃焼室内の最高燃焼温度を下げ、熱発生型NOx（サーマルNOx）の生成を根本から大幅に抑制します。
