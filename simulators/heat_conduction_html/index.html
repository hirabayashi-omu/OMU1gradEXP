非定常熱伝導と空間・時間離散化の基礎理論

1. 支配方程式（熱伝導方程式）

3次元空間における非定常熱伝導の支配方程式は以下の通りです。

$$\rho c\frac{\partial T}{\partial t}=\frac{\partial }{\partial x}\left(k\frac{\partial T}{\partial x}\right)+\frac{\partial }{\partial y}\left(k\frac{\partial T}{\partial y}\right)+\frac{\partial }{\partial z}\left(k\frac{\partial T}{\partial z}\right)+Q$$

  • \(\rho \): 密度 (\(\text{kg/m}^{3}\))
  • \(c\): 比熱 (\(\text{J/(kg}\cdot \text{K)}\))
  • \(T\): 温度 (\(\text{K}\) または \({}^{\circ }\text{C}\))
  • \(t\): 時間 (\(\text{s}\))
  • \(k\): 熱伝導率 (\(\text{W/(m}\cdot \text{K)}\))
  • \(Q\): 内部発熱量 (\(\text{W/m}^{3}\))

左辺の \(\rho c \frac{\partial T}{\partial t}\) が、時間変化に伴う熱エネルギーの蓄積（または放出）を表しています。

2. 有限要素法（空間離散化）によるマトリクス方程式

有限要素法（ガラーキン法など）を適用して空間を要素に分割すると、全体系の連立常微分方程式は以下のマトリクス形式に変換されます。

$$[C]\left\{\frac{\partial T}{\partial t}\right\}+[K]\{T\}=\{F\}$$

  • \([C]\): 熱容量マトリクス（あるいは比熱マトリクス）。物体が熱をどれだけ蓄えられるかを示します。
  • \([K]\): 熱伝導マトリクス。要素間の熱の伝わりやすさを示します。定常解析の剛性マトリクスに相当します。
  • \(\{T\}\): 各節点の温度ベクトル
  • \(\left\{\frac{\partial T}{\partial t}\right\}\): 各節点の温度の時間微分ベクトル
  • \(\{F\}\): 熱荷重ベクトル。内部発熱、境界からの熱流束、対流熱伝達、放射などが含まれます。

3. 時間の離散化手法（時間軸の解法）

上記の式は時間に関する微分方程式であるため、時間軸を微小時間 \(\Delta t\) ごとに区切って解く必要があります。一般的に差分法（\(\theta \) 法）が用いられます。
時刻 \(n\) の温度 \(\{T\}_n\) から、次の時刻 \(n+1\) の温度 \(\{T\}_{n+1}\) を求めるため、時間微分を以下のように近似します。

$$\left\{\frac{\partial T}{\partial t}\right\}\approx \frac{\{T\}_{n+1}-\{T\}_{n}}{\Delta t}$$

これをマトリクス方程式に代入し、重み係数 \(\theta \) （\(0 \le \theta \le 1\)）を用いて整理すると以下のようになります。

$$\left(\frac{1}{\Delta t}[C]+\theta [K]\right)\{T\}_{n+1}=\left(\frac{1}{\Delta t}[C]-(1-\theta )[K]\right)\{T\}_{n}+\theta \{F\}_{n+1}+(1-\theta )\{F\}_{n}$$

\(\theta \) の値によって、以下の3つの代表的なスキームに分かれます。

スキーム名\(\theta \) の値特徴と安定性
前進差分法（陽解法）\(\theta = 0\)連立方程式を解く必要がなく計算が高速。ただし、\(\Delta t\) を非常に小さくしないと解が発散する（条件付き安定）。
クランク・ニコルソン法\(\theta = 0.5\)時間方向に対して2次の精度を持ち、最もバランスが良い。無条件安定。
後進差分法（陰解法）\(\theta = 1.0\)計算ごとに連立方程式を解く必要があり負荷が高いが、\(\Delta t\) を大きくしても絶対に発散しない（無条件安定）。汎用FEMソフトで最も一般的。

4. 非定常伝熱計算に必要な境界条件と初期条件

計算を実行するには、空間の境界条件だけでなく、時間のスタートラインを決める必要があります。

  • 初期条件（必須）: \(t = 0\) における全節点の初期温度分布。
  • 境界条件（時間変化させることが可能）:
    • 固定温度（ディリクレ境界）: 壁面の温度を一定、または時間依存で強制指定。
    • 熱流束（ノイマン境界）: 外部から流入する単位面積あたりの熱量。
    • 熱伝達（ロビン境界）: 周囲の流体（空気や水）との間の熱交換（\(q = h(T - T_\infty)\)）。
