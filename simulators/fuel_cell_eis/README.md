# 燃料電池 電気化学インピーダンス (EIS) & 4端子法 Cole-Coleプロット シミュレータ

燃料電池（PEFC / SOFC）を対象とした電気化学インピーダンス分光法（EIS: Electrochemical Impedance Spectroscopy）シミュレータです。
周波数応答分析器（FRA）および4端子LCRメータを用いたKelvin結線のグラフィカルな配線可視化と、等価回路モデルに基づくCole-Cole（Nyquist）プロット・Bodeプロットのリアルタイム解析・測定シミュレーションを提供します。

---

## 主な機能

### 1. 4端子法（Kelvin結線）インタラクティブ配線グラフィック
- **FRA+ポテンショスタット / 4端子LCRメータ** の結線構造をSVGアニメーションで図示。
- 電流印加端子（$I_{cur}^+, I_{cur}^-$）と電圧センス端子（$V_{pot}^+, V_{pot}^-$）が燃料電池単セル（MEA・ガス流路・集電板）へ接続される様子を可視化。
- **4端子法 vs 2端子法の切り替え**:
  - 2端子測定時にリード線抵抗・接触抵抗（$2 \times R_{lead}$）が重畳して高周波切片 $R_\Omega$ が見かけ上増大する現象をワンクリックで比較検証可能。

### 2. 燃料電池等価回路物理モデル
- **電解質膜オーム抵抗 $R_\Omega$**: 高周波実軸切片（HFR）。電解質膜（Nafion等）のプロトン伝導抵抗および接触抵抗。
- **アノード反応（HOR）$R_{ct,a} \parallel C_{dl,a}$**: 水素酸化反応に伴う高周波側（100 Hz〜5 kHz）の小円弧。
- **カソード反応（ORR）$R_{ct,c} \parallel \text{CPE}_c$**: 酸素還元反応に伴う中周波側（1 Hz〜100 Hz）の主半円。緩和周波数 $f_{max} = \frac{1}{2\pi R_{ct} C_{dl}}$。
- **多孔質ガス拡散層（GDL）物質移動 $Z_W$**: 有限長Warburg拡散インピーダンス。低周波側（0.01 Hz〜1 Hz）の45°直線・テール。
- **配線インダクタンス $L_{cable}$**: 高周波側（10 kHz〜100 kHz）の第4象限ループ。

### 3. Cole-Cole（ナイキスト線図）& Bodeプロット
- 高解像度Canvasによる高速・滑らかな描画。
- 実時間での周波数点ホバーインスペクション（周波数 $f$, 実部 $Z'$, 虚部 $-Z''$, 振幅 $|Z|$, 位相 $\theta$ の表示）。
- **等価回路素子とグラフの双方向連動**: 回路素子にマウスを乗せると、対応する周波数帯・円弧領域をグラフ上でハイライト表示。
- **スイープ測定シミュレーション**: $100\text{ kHz} \rightarrow 0.01\text{ Hz}$ の周波数スキャンをリアルタイムで点描実行。
- **CSVデータ出力**: 各周波数の測定値をCSV形式でダウンロード可能。

### 4. プリセット運転状態
- 🌟 **正常運転 (Normal Operation)**
- 💧 **フラッディング (Cathode Flooding)**: GDL生成水閉塞による $R_W$ 増大
- 🏜️ **電解質膜乾燥 (Membrane Dry-out)**: 加湿不足による $R_\Omega$ 増大
- ⚡ **触媒劣化 / CO被毒 (Catalyst Degradation / Poisoning)**: $R_{ct}$ の肥大化
- 🔌 **2端子測定時のリード線誤差 (2-Wire Artifact)**: 接触抵抗の重畳
- 🔬 **SOFC 高温運転 (Solid Oxide Fuel Cell ~750℃)**

### 5. 等価回路による解釈ガイド
- 各等価回路素子の物理的意味・数式
- Cole-Coleプロットの読み方（切片・円弧直径・頂点周波数・テールの解釈）
- 燃料電池の不具合パターンの見分け方（膜乾燥 vs フラッディング vs 触媒劣化）
- 4端子法による接触抵抗除去の原理
